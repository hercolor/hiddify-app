# BflyVPN 设计系统 v1

**文档状态：** 设计基线，落地依据
**日期：** 2026-07-30
**适用：** Android + Windows（共用一套 390×910 竖向形态）
**上游依据：** `product-definition-v0.1.md` v0.2 §6「正式应用级 UI，非 Demo」

---

## 0. 四条已冻结的方向决策

| 决策 | 结论 | 理由 |
|------|------|------|
| 视觉风格 | **浅色高对比 + 靛紫→青品牌渐变** | 品牌标识是纯黑蝴蝶，深色会让它消失；VPN 品类扎堆深色，浅色是差异化 |
| Windows 形态 | **与 Android 共用手机形态** | 两端体验一致，托盘/关闭弹窗逻辑不动 |
| 深色模式 | **首发不做** | 锁定单一主题保证首发质量，双主题留 v1.1 |
| 普通用户路由控制 | **不提供** | 客户端使用锁定策略，技术配置仅在隐藏诊断中可见 |

---

## 1. 设计原则

1. **一个页面只有一个主决策。** 连接页决定连不连，节点页决定去哪，我的页决定账号。首页不放第二个开关。
2. **技术语言零露出。** 协议、端口、DNS、订阅地址、fake-ip 不出现在任何普通用户可达的界面。节点只以「地区 + 编号」呈现。
3. **状态必须有出口。** 任何失败态都要有一句人话 + 一个主按钮。禁止无限转圈，禁止「连接失败」吞掉所有原因。
4. **颜色只从 token 取。** 新代码出现字面量颜色视为缺陷。

### 2.2 品牌色

| Token | 值 | 用途 |
|-------|-----|------|
| `brand` | `#4F46E5` | 主色：主按钮、选中态、强调文字、已连接 |
| `brandDeep` | `#3730A3` | 按下态、渐变深端 |

> **硬性约束：** `brandGlow #22D3EE` 在白底上对比度仅 **1.81:1**，
> **禁止**用作任何文字或需要辨识的图标颜色。它只能作为渐变的一端、
> 或大面积图形填充出现。这条不是偏好，是可访问性下限。

`brand #4F46E5` 白底对比度 **6.3:1**，正文与图标均达 AA。

**主渐变：** `#4F46E5 → #22D3EE`，135°（左上→右下）。仅用于连接大按钮、会员卡片、主 CTA。

| `warning` | `#F59E0B` | 待确认、延迟 50–150ms、支付状态未知 |
| `danger` | `#EF4444` | 失败、到期、延迟 >150ms、退出登录 |

## 5. 三主页布局

### 5.1 连接页

```
┌─────────────────────────┐
│  ⚙        BflyVPN     ✕ │  56  顶栏（⚙ 仅诊断入口 / ✕ 仅 Windows）
├─────────────────────────┤
│ ┌────────┐ ┌─────────┐  │  72  速度双卡（下载 / 上传）
│ └────────┘ └─────────┘  │
│                         │
│         ╭───────╮       │      连接主按钮 176×176
│        │  渐变   │      │      未连接：wash 底 + inkFaint 图标
│        │   ╳╳    │      │      连接中：brand 描边呼吸
│        │  已连接  │      │      已连接：主渐变 + glow
│         ╰───────╯       │
│         00:15:32        │  32  仅已连接时出现
│                         │
│ ┌─────────────────────┐ │  64  当前节点卡（点击进节点页）
│ │ 🇭🇰 香港 01    32ms ›│ │
│ └─────────────────────┘ │
├─────────────────────────┤
│   连接    节点    我的   │  78  底部导航
└─────────────────────────┘
```

**关键改动：** 移除原先位于节点卡下方的「全局 / 智能分流」分段控件，普通用户不再修改路由策略。

### 5.2 节点页

- 顶部：标题 + 「测速」文字按钮（非图标，避免歧义）
- 列表项：`旗帜 emoji + 地区名 + 编号` ｜ 右侧延迟数字
- 延迟着色：`<800ms success` / `800–1500ms warning` / `>1500ms danger` / 未测或超时 `inkFaint 显示「--」`
- 选中项：左侧 3px `brand` 竖条 + 卡片底 `wash`
- **禁止出现**：IP、端口、协议名、订阅地址

> **阈值为什么不是 50/150ms：** 那是直连场景的通用网络延迟标准。
> 经隧道访问境外节点的实测延迟极少低于 50ms，按该标准几乎全部节点会显示为红色，
> 颜色就失去了区分能力。800/1500 对应代理场景下「顺畅 / 可用 / 建议更换」三档。

### 5.3 我的页

```
会员卡（深色渐变底 vipCardTop→ink，白字 + 金色徽标）
  套餐名 · 到期时间 · 设备 x/y
  ├ 有效：显示剩余天数
  └ 未开通/到期：卡片转 wash 底，CTA「开通会员」

流量统计（纯展示，不含任何拦截语义）
  已用 / 总量，进度条 brand

账号
  安全中心 › ｜ 邀请 › ｜ 联系客服 ›

退出登录（danger 文字按钮）
```

诊断信息不设置可见菜单入口，仅保留「关于」页版本号连续点击的隐藏入口。

> **会员卡为什么不用主渐变：** 主渐变已被连接大按钮占用，是页面里最强的视觉信号。
> 会员卡若复用同一渐变会造成层级竞争。改用深色底 + 金色徽标，
> 让它成为浅色界面里唯一的深色锚点，与连接按钮各占一个视觉焦点。

## 6. 关键状态（每个都必须有文案 + 主按钮）

| 状态 | 呈现 | 文案 | 主按钮 |
|------|------|------|--------|
| 未登录 | 按钮禁用 `wash` | 请先登录账号 | 去登录 |
| 登录过期 | 同上 | 登录已过期，请重新登录 | 去登录 |
| 未开通 | 按钮禁用 | 请先开通会员 | 去开通 |
| 已到期 | 按钮禁用 | 会员已到期，请续费 | 去续费 |
| **设备超限** | 按钮禁用 | 登录设备已达上限（当前 x / 上限 y） | 我知道了 / 联系客服 |
| 无节点 | 节点卡显示空态 | 暂无可用节点，请稍后重试 | 重试 |
| 连接中 | `brand` 描边呼吸动效 | 正在连接… | （可取消） |
| 已连接 | 主渐变 + glow + 计时 | 已连接 | 断开 |
| 连接失败 | 按钮回到未连接 + danger toast | 按 L0–L6 分层文案 | 按层给主按钮 |
| 支付确认中 | 套餐页状态条 `warning` | 正在确认支付结果 | 刷新支付状态 |
| 支付成功 | 状态条 `success` | 会员已生效 | 知道了 |

> 流量耗尽**不是**状态，不出现在此表——流量已退出门禁，只在我的页做统计展示。

## 7. 落地约束

1. **不新增二进制设计资产。** 品牌标识复用 `icon.png` 及其派生的 mipmap，启动页已接入。
2. **token 单一来源** 为 `lib/core/theme/brand_theme.dart`。字面量颜色在评审中视为缺陷。
3. **Windows 与 Android 共用组件树**，窗口锁 390×910，不为桌面单开布局分支。
4. 深色资源目录（`values-night*`）保留但不投入设计，v1 全部走浅色值。
